## 4. Class Feedback
- A bug where the "create account" button still existed after sign in: We knew this bug was thing and immediately pointed it out when we did a practice demo but we didn't have enough time polishing the site. Next time we'll try not to cram features in before the deadline so we can have more active feedback.
- Couldn't tell if studysets were saved after a refresh: Studysets do get saved and the set ids are tied to each user account, maybe we could've explained the process better and showed the schema. 
- No Gaming aspect of the site: We made it clear, the gaming aspect will be implemented in sprint 2 because we wanted to create the structure of studyquest first and add core functionality like creating accounts and saving studysets. We'll implement xp bars, virtual currency, and a few game modes for a sprint 2.
- No responsive design: We didn't have a finalized design and were using placeholders. We didn't want to go back and forth when making changes, but we understand by doing that it may create more work. For sprint 2, we'll have a finalized design with responsive design that fits for all devices.
